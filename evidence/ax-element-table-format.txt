# 1. AXIdentifier on Apple apps is often an internal '_NS:<n>' string, NOT a human label.
#    Resolving AXIdentifier FIRST yields names like "_NS:61" that are useless to a
#    text-only model — and contradicts SPEC §7.1's own 'tie-breaker only' intent.
# 2. AXWindow does not report kAXEnabledAttribute, so 'enabled' renders as 'disabled'
#    for windows. nil (not applicable) must not be shown as disabled.
# 3. Candidate volume far exceeds the 24-cap: 346 of 510 Finder nodes and 519 of 784
#    Safari nodes are named+actionable. Ranking/pruning is mandatory, not optional.
# 4. Budget: 510-node tree ~14.5k tokens, 784-node tree ~24.6k tokens. A 28k budget is
#    workable but Safari already sits at ~88% of it.
